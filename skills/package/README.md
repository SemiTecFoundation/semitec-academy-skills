# Package learning materials

Bundle standalone trainings, labs, projects and other materials using the [package skill](SKILL.md).
The current builder targets Academy 2.1.0+. Course order and study plan are required. Package and training
certificates are optional author/publisher choices. New certificate designs use HTML/CSS/JavaScript.

Read the [specification](reference/pack-spec.md), [archive layout](reference/archive-layout.md), and
[format table](reference/formats.md). Academy downloads complete item folders, including sources and
supporting materials. Learner downloads exclude author preview HTML by default. An optional package password can authorize previews after a successful unlock.
