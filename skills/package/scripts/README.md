# stlp (bundled)

Self-contained copy of the SemiTec Academy package builder, generated by
`node packer/stlp.js bundle-skill` from SemiTec Academy 1.6.2 (see VERSION.json). Needs Node.js 18+, nothing to install.

    node stlp.js check  pack-spec.json
    node stlp.js create pack-spec.json --key <private.pem>   (or --unsigned)

Do not edit — regenerate from the Academy repository (https://github.com/SemiTecFoundation/semitec-academy) when the app changes.
