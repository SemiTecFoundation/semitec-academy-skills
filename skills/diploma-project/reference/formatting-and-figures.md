# Formatting, Figures & Tables

Conventions for a clean, consistent academic document. Adjust to the author's
institutional style guide where one exists.

## Page & text
- A4, margins ~2.5 cm (bind side a little wider if printed).
- Body text 11–12 pt, serif (e.g. Times/Georgia) or the institution's font;
  line spacing 1.15–1.5.
- Justified body text; headings left-aligned.
- Page numbers: front matter in roman numerals (i, ii, …), body in arabic (1, 2, …).

## Headings
- Numbered, up to three levels: `1`, `1.1`, `1.1.1`. Avoid deeper nesting.
- Consistent style per level; start each top-level chapter on a new page.

## Figures
- **Every figure is numbered and captioned** below the image: *Figure 3.2:
  System architecture.* Number by chapter (3.1, 3.2 …).
- **Reference every figure in the text** before it appears ("as shown in
  Figure 3.2"). No orphan figures.
- Keep diagrams legible in black and white; label axes and units on plots.
- Common diagrams to include where relevant: system **architecture**, **data
  model / ER diagram**, process **flowchart**, **sequence** of operations,
  results **charts** (bar/line/scatter). Use a diagram, not prose, for structure.

## Tables
- Numbered and captioned **above** the table: *Table 4.1: Evaluation results.*
- Reference each table in the text.
- Keep them simple: header row, aligned columns, units in the header, a note row
  for sources/caveats if needed.

## Equations
- Displayed and numbered on the right: `(3.1)`. Define every symbol on first use.

## Citations & references
- Pick **one** citation style and use it throughout — IEEE (numeric [1]) is common
  for engineering; APA/Harvard (author, year) for many other fields. Ask the
  author which their institution requires.
- Every in-text citation has a matching reference entry, and vice versa.
- Never fabricate a reference. If a source is missing, leave `[CITATION NEEDED]`.

## Placeholders
While drafting, mark gaps explicitly so they're easy to find:
`[TODO: …]`, `[FIGURE: …]`, `[CITATION NEEDED]`, `[DATA: …]`.
