# images/

Put image files here (`.png`, `.jpg`, or vector `.pdf`) and insert them with:

```latex
\addimage[fig:label]{images/yourfile.png}{0.6}{Your caption.}
```

`0.6` is the width as a fraction of the text width; the image is centered and
captioned automatically. Prefer **vector PDF** for diagrams and charts, and
high-resolution PNG/JPG for screenshots and photos.

`example-placeholder.png` is a dummy image used by the template's example — replace
it with your own.
