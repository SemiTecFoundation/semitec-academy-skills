\chapter{Ընդլայնումներ (ընտրովի)}
\label{ch:extensions}

Ստորև բերվածները \textbf{պարտադիր չեն}. դրանք կարող են բարձրացնել գնահատականը կամ դառնալ մագիստրոսական թեզի հիմք.
\begin{itemize}
  \item \textbf{AXI DMA / DDR ուղի} — բարձր տվյալահոսքի համար։
  \item \textbf{FPGA reconfiguration} — նախապես գեներացված bitstream-ների ընտրություն Web հարթակից։
  \item \textbf{Ֆիզիկական սենսորներ} — էմուլացված աղբյուրների փոխարեն կամ կողքին։
  \item \textbf{Ադապտիվ հետադարձ կապ (closed loop)} — սերվերի մոդելը ավտոմատ փոխում է FPGA-ի պարամետրերը։
  \item \textbf{Linux Zynq PS-ի վրա} — սերվերային բաղադրիչների մասնակի տեղափոխում։
\end{itemize}
