\chapter{Ամփոփ ցուցադրման սցենար}
\label{ch:demo}

\begin{enumerate}
  \item Օգտվողը բացում է Web հարթակը, ընտրում \textbf{Vibration} սենսորը և \textbf{Periodic} ազդանշանը։
  \item Կոնֆիգուրացնում է sample rate, ամպլիտուդ, աղմուկ, threshold, filter, anomaly և սեղմում \textbf{Start Experiment}։
  \item Backend-ը կոնֆիգուրացիան ուղարկում է AUP ZU3-ին. Zynq PS-ը գրում է այն AXI4-Lite ռեգիստրներում։
  \item FPGA-ն գեներացնում է վիբրացիանման տվյալներ և կատարում իրական ժամանակի մշակում։
  \item Տվյալները PS-ից Ethernet-ով հասնում են սերվեր և պահվում բազայում։
  \item Dashboard-ը ցուցադրում է raw և processed ազդանշանները իրական ժամանակում։
  \item FPGA-ն ներարկում է անոմալիա. threshold detector-ը և սերվերային մոդելը հայտնաբերում են այն։
  \item Հարթակը համեմատում է FPGA-ի հայտնաբերումը և ծրագրային վերլուծությունը։
  \item Օգտվողը փոխում է FPGA-ի պարամետրերը, և վարքը փոխվում է \textbf{runtime}-ում՝ առանց bitstream վերագեներացնելու։
\end{enumerate}
