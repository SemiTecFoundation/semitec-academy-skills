# Defense Slides Outline

A defense/presentation deck derived from the document. Target **12–16 slides** for
a 15–20 minute defense. One idea per slide; figures over text.

1. **Title** — project title, author, supervisor, institution, date.
2. **Motivation & problem** — why this matters; the problem in one sentence.
3. **Objectives / research questions** — 2–4 bullet goals.
4. **Background** (1–2 slides) — key concepts and the gap in existing work.
5. **Approach / methodology** — the method, at a glance (a diagram works well).
6. **Design / system** (1–2 slides) — architecture or study design diagram.
7. **Implementation highlights** — the few decisions worth showing.
8. **Experimental setup** — data, metrics, baselines.
9. **Results** (2–3 slides) — the key charts/tables, one finding per slide.
10. **Discussion** — what the results mean; limitations.
11. **Conclusion** — contributions mapped to the objectives.
12. **Future work** — 2–3 concrete directions.
13. **Thank you / Questions** — contact + acknowledgements.
14. **Backup slides** (optional) — extra detail for likely questions.

Guidance:
- Pull figures directly from the document so the talk and the thesis match.
- Keep each slide to a headline claim plus supporting visual; move prose to the
  speaker notes.
- Mirror the document's section order so examiners can follow both together.
