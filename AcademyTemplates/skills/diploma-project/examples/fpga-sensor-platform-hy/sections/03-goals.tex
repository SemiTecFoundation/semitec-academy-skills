\chapter{Նպատակներ և խնդիրներ}

Նախագծի հիմնական նպատակներն են.
\begin{enumerate}[leftmargin=1.6em]
  \item FPGA-ի ներսում իրականացնել կոնֆիգուրելի սենսոր-էմուլյացիա (RTL ազդանշան-գեներատորներ)։
  \item Իրականացնել իրական ժամանակի նախնական մշակում (processing IP-ներ) FPGA-ի վրա։
  \item Ապահովել PL$\rightarrow$PS տվյալների փոխանցում և PS$\rightarrow$սերվեր հաղորդակցություն։
  \item Մշակել սերվեր, տվյալների բազա և Web հարթակ՝ պահպանման, վիզուալիզացիայի և վերլուծության համար։
  \item Ապահովել FPGA-ի \textbf{runtime կոնֆիգուրացիա} Web հարթակից՝ AXI4-Lite ռեգիստրների միջոցով։
  \item Ցուցադրել համակարգի ամբողջական աշխատանքը՝ փորձի (experiment) կազմակերպման, տվյալների հավաքագրման և վերլուծության միջոցով։
\end{enumerate}
