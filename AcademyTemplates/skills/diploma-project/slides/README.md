# slides/

A **presentation template** for the diploma/thesis defense will live here — as a
second, independent part of this template package (an author can use the LaTeX
document, the slides, or both).

Two options are planned; tell us which you prefer:

- **Beamer** (LaTeX) — matches the document's look, same TikZ diagrams and
  citations, builds to PDF slides. Fits authors already writing in LaTeX.
- **PowerPoint (.pptx)** — an editable deck for authors who prefer PowerPoint.

The slide *content* structure is already defined in
`../reference/slides-outline.md` (title, motivation, objectives, method, results,
conclusion, …). This folder will hold the actual template once we pick the format.
