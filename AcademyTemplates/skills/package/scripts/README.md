Self-contained copy of the SemiTec Academy package builder, generated by
`node packer/stlp.js bundle-skill` from Foundation/Products/Academy 1.6.0 (see VERSION.json). Needs Node.js 18+, nothing to install.

    node stlp.js check  pack-spec.json
    node stlp.js create pack-spec.json --key <private.pem>   (or --unsigned)

Do not edit — regenerate from Foundation/Products/Academy when the app changes.
